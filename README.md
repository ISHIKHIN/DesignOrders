# DesignOrder - система учёта заказов на дизайн

## Назначение

Приложение для приёма, оценки и распределения заказов на дизайнерские
услуги. Позволяет менеджеру создать заказ, рассчитать стоимость
с учётом срочности, назначить дизайнера и отслеживать сроки выполнения.
Решает проблему учёта заказов, которые сейчас теряются в переписке
и таблицах.

## Целевая аудитория

- дизайн-студии и агентства;
- фрилансеры-дизайнеры;
- менеджеры, работающие с клиентскими заказами;
- руководители, контролирующие загрузку дизайнеров.

## Предметная область
Оказание дизайнерских услуг заказчикам - приём заявок на разработку логотипов, баннеров, упаковок и другого, оценка стоимости и сроков, назначение дизайнеров с учётом их загрузки, контроль выполнения заказа и соблюдения дедлайнов.

## Основные сущности

- Клиент 
- Заказ
- Дизайнер 
- Этап 

## Основные функции

- `create_order()` — формирование описания заказа с данными клиента,
  дизайнера, стоимости и срока;
- `client()` — вывод контактных данных заказчика;
- `deadline_soon()` — проверка близости дедлайна (скоро / просрочен /
  нескоро);
