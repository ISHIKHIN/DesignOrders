# DesignOrder - система учёта заказов на дизайн

## Назначение

Приложение для приёма, оценки и распределения заказов на дизайнерские
услуги. Позволяет менеджеру создать заказ, рассчитать стоимость
с учётом срочности, назначить дизайнера и отслеживать сроки выполнения.
Решает проблему учёта заказов, которые сейчас теряются в переписке
и таблицах.

## Целевая аудитория

- дизайн-студии и агентства;
- фрилансеры-дизайнеры;
- менеджеры, работающие с клиентскими заказами;
- крупные компании или физические лица со своим бизнесом.

## Предметная область

Приём и учёт инструментов, отслеживание состояния каждого инструмента, изменение цены, бронирование инструментов покупателями, контроль доступности.

## Основные сущности

- Клиент
- Заказ
- Дизайнер
- Дедлайн

## Основные функции

- `add_client()` - добавление клиента;
- `find_client()` - поиск клиента по подстроке имени;
- `show_clients()` - вывод списка клиентов;
- `add_designer()` - добавление дизайнера;
- `find_designer()` - поиск дизайнера по подстроке имени;
- `show_designers()` - вывод списка дизайнеров;
- `create_order()` - создание заказа с данными клиента, дизайнера,
  стоимости и срока;
- `cancel_order()` - отмена заказа по идентификатору;
- `find_orders_by_client()` - поиск заказов клиента;
- `sort_orders_by_deadline()` - сортировка заказов по дедлайну;
- `filter_orders_by_urgency()` - фильтрация срочных заказов;
- `deadline_status()` - проверка близости дедлайна (скоро / просрочен /
  нескоро).

## Структура проекта

- `main.py` - точка запуска и меню приложения;
- `clients.py` - работа с клиентами;
- `designers.py` - работа с дизайнерами;
- `orders.py` - работа с заказами;
- `storage.py` - сохранение и загрузка данных;
- `utils.py` - вспомогательные функции (безопасный ввод);
- `data/` - JSON-файлы данных;
- `tests/` - автоматизированные тесты;
- `README.md` - документация проекта;
- `requirements.txt` - зависимости проекта.

## Формат хранения данных

- `data/clients.json` - словарь `id → {name, phone}`;
- `data/designers.json` - словарь `id → {name, specialization}`;
- `data/orders.json` - список словарей заказов.
